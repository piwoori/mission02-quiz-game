# 나만의 퀴즈 게임

Python 기본 문법과 객체지향 프로그래밍, 파일 입출력, Git 사용법을 학습하기 위한 콘솔 퀴즈 게임입니다.

## 프로젝트 개요

터미널에서 실행되는 객관식 퀴즈 게임입니다.

사용자는 퀴즈를 풀거나 새로운 퀴즈를 추가할 수 있으며, 등록된 퀴즈 목록과 최고 점수를 확인할 수 있습니다.

퀴즈 데이터와 최고 점수는 `state.json` 파일에 저장되어 프로그램을 종료한 후에도 유지됩니다.

quizzes: 등록된 퀴즈 목록
best_score: 최고 점수

예상 데이터 구조:

{
  "quizzes": [
    {
      "question": "문제 내용",
      "choices": [
        "선택지 1",
        "선택지 2",
        "선택지 3",
        "선택지 4"
      ],
      "answer": 1
    }
  ],
  "best_score": 0
}
